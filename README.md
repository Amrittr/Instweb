# arts.withankita website

Website for arts.withankita, a small handmade home décor and resin art studio: the maker's story, how pieces are made in small batches, and a showcase of products such as wind chimes and diyas.

## Files

- `index.html`, `style.css`, `app.js`: the site
- `assets/`: product photos and images

Static site: plain HTML, CSS and JavaScript, no build step. Open `index.html` in a browser to run it locally. Deployed on Vercel.
